## 经验沉淀(全阶段)

### 1. `test.skip` 位置:describe 顶部 > test 体内
P1 修:d2prime-30s + d3-demo + diag-sidenav + diag-launch。fixture 解析在 test 体内 skip 之前,所以必须 describe 级 skip。

### 2. Vue Router hash 模式 + Playwright
`window.goto('#/route')` 报 invalid URL。正确:`window.evaluate(() => { window.location.hash = '#/route' })` + `waitForURL`。

### 3. Electron mock 路径对齐
SelfLearner 写 `getAppPath() + '/../skills'`,SkillLoader 读 `getPath('userData') + '/skills'`。Test mock 必须让两者解析到同一目录(让 getAppPath 返回子路径如 `userData/app`)。

### 4. LLM 真链路的证明方法
加 mock LLM HTTP server(Node http.createServer),`LlmClient.chat({ apiBaseUrl: '...' })` 真 fetch,验证响应含 marker。`mocked adapter` ≠ `真 LLM 链路`。

### 5. SandboxBuilder 模板数 vs 测试期望
不强求最少文件数,`t.minFiles` 参数化;只验关键文件存在 + size > 0。

### 6. ANSI color codes 破坏 stdout 解析
`npx vitest --reporter=basic` 输出带 ANSI。`replace(/\u001b\[[0-9;]*m/g, '')` 剥掉再 regex。

### 7. Skill.md 格式约束
`parseSkillMd` 要求 `# name + ## 描述 + ## 触发关键词 + ## 操作步骤`,`## Hot Reload` 不会被认作 name。Test 必须按规范构造。

### 8. ErrorClassifier 模式覆盖
"unexpected token" 不匹配任何 pattern(unknown) → 不重试。Test 用 `json parse` / `syntax error` 等明确字串。
