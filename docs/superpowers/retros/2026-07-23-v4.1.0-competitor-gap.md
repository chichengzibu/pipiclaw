## 关键决策

### 1. ChannelRouter.send 真实集成替代 stub

`channel:send` IPC 原本是 stub,直接返回 `{ success: true, data: { stub: true } }`。
P2-01 把它接入 `ChannelRouter.send()`,通过 EventBus 发布 `im:channel:send:ok` / `im:channel:send:fail`。
**意外收获**:9 个 ChannelRouter 单测覆盖了完整生命周期(register/unregister/listByKind/healthCheckAll/连续 send),
这些基础设施层测试在之前一直缺失。

### 2. ClawHub 模板:用 source='template' + templateId 字段,而不是新表

考虑过新建 `ClawHubTemplateStore` 和 `clawhub-templates.json`,但最终选 source 扩展:
- 复用 ClawHubManager 的所有基础设施(search/review/rate/persist)
- 模板实例化自然产生 pending skill,直接进审核流
- 数据模型更紧凑,前端不用多套 UI

### 3. 6 个内置模板 vs 用户上传模板

只做内置模板,理由:
- 模板质量 > 数量
- 内置模板反映 PiPiClaw 的核心场景(日报/周报/审查/翻译)
- 用户上传模板需要模板审核 + 防滥用机制,scope creep
- Stage 2 再加社区模板 + 评分

### 4. P2-04 (权限 JSON 导入/导出) 顺带做

本来 P2 计划是 P2-01 → P2-02 → P2-03 顺序,但发现
`IMPermissionManager.listAll` 已经在 P0-05 加过,export/import 只差
`JSON.stringify` 和 `JSON.parse` 一点点代码,顺手做掉。

### 5. 测试策略:基础设施层 + 业务层 + UI 层

每个 Phase 都按 3 层覆盖:
- **基础设施层**(Manager / Store):单元测试,快速
- **业务层**(IPC handler):用 vitest 集成,验证序列化
- **UI 层**(Vue 组件):mount + flushPromises,验证 props + events + 调 IPC

## 痛点 / 教训

### 1. 错误信息 stringification 一致性

ChannelRouter.send 失败时 `String(new Error('x'))` 返回 `'Error: x'`,而我们有些测试期望 `'x'`。
Lesson:`expect(error).toContain('...')` 比 `toBe` 更鲁棒。
已修复。

### 2. 模板的 EventBus 事件 vs 模板直接状态变更

instantiateTemplate 内部用了 EventBus,测试用 `setTimeout(0)` 等异步。
Lesson:EventBus.publish 是 async,handler 的调用顺序是 await microtask 之后。
后续可考虑提供 `await bus.waitFor(topic)` 工具。

### 3. view test 中 mock IPC 的全局污染

`clawhubInstantiateTemplate` 的 mock 改了之后,后续测试 if 没有 reset,会污染。
Lesson:`beforeEach` 用 `vi.clearAllMocks()` 或每个 test 自己 override。

### 4. Vue SFC 中 `:deep` 嵌套选择器

`.template-card :deep(.el-card__body)` 这种 selector 在 vue-tsc 中没问题,
但生成的 CSS 顺序会影响 specificity。
Lesson:尽量在 scoped 块外面用通用 class,避免依赖 element-plus 内部 class。

## 关键代码片段

### ClawHubManager.instantiateTemplate

```ts
instantiateTemplate(args) {
  const tpl = this.templates.get(args.templateId)
  if (!tpl) throw new Error(`template ${args.templateId} 不存在`)
  const dir = path.join(app.getPath('userData'), 'templates', `skill-${randomUUID().slice(0, 8)}`)
  fs.mkdirSync(dir, { recursive: true })
  const manifestPath = path.join(dir, 'skill.md')
  fs.writeFileSync(manifestPath, tpl.manifestContent, 'utf-8')
  const skill: ClawHubSkill = {
    ...,
    source: 'template',
    templateId: tpl.id,
    status: 'pending',  // 必须审核才进 search
  }
  this.skills.set(skill.id, skill)
  this.persist()
  void this.bus.publish('clawhub:template-instantiated', { skillId, templateId })
  return skill
}
```

### ChannelRouter.send

```ts
async send(channelId, message) {
  const channel = this.channels.get(channelId)
  if (!channel) return { ok: false, error: `channel ${channelId} not found` }
  try {
    await channel.send(message)
    void this.bus.publish('im:channel:send:ok', { channelId })
    return { ok: true }
  } catch (e) {
    void this.bus.publish('im:channel:send:fail', { channelId, error: String(e) })
    return { ok: false, error: String(e) }
  }
}
```
