04 / 06

焦点环: 缺失 → 完整无障碍

v4.3.1 的 focus 环是 Element Plus 默认,深色主题下基本看不见。1 改 token 后用 :focus-visible + 2px outline + 2px offset,键盘用户和鼠标用户都能看清。

*:focus { outline: none }  +  *:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }

1 改 token 路线 — 6 步执行

单 commit 落地,不允许动业务代码、路由、组件、文档。整套变更只在样式层。

  1. STEP A
    新建 src/styles/tokens.scss
    4 档 spacing / 4 档 radius / 3 档 shadow / 4 duration × 3 easing — 跟 Linear 路线对齐
  2. STEP B
    焦点环 global.scss
    *:focus-visible 加 2px outline + 2px offset,深色主题下可见
  3. STEP C
    砍 2 套主题 theme-v4.3-to-v4.4.ts
    写 migration 把已有用户的 purple→dark, blue→light,不影响 light/dark 用户
  4. STEP D
    密度调整
    行高 32→28, padding 12 16 → 8 12 (4 档 token 替换 + sed 批量)
  5. STEP E
    验证
    vitest 905 pass / e2e 102 pass / visual regression 11 张截图对比
  6. STEP F
    单 commit
    feat(ui): 1 改 token - 统一 spacing + 焦点环 + 砍 2 套主题
