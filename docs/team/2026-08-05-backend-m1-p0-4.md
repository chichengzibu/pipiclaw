## 关键设计决定

1. **静态 import vs require 决策** — esbuild bundle 后 `require(相对路径)` 在 bundled main.js 里失效 (bundle 是 single file, 路径语义变了). 静态 import 让 esbuild 把 D5RecordingToSkill 打进 bundle, runtime 通过 Symbol resolve 找到. 这是 esbuild 项目的标准实践.
2. **顶部 import 一次, 2 处 handler 共用** — 不在每个 handler 里 `await import()` (动态), 一次性顶部静态 import, 运行时同步可用. esbuild tree-shaking 不去掉 (因为 2 处 handler 都用).
3. **不改 D5RecordingToSkill.ts 本身** — 文件已正确 export `runD5` (line 28) + `registerD5RecordingToSkill` (line 90), 静态 import 直接用, 不用动 builtin 源文件.
