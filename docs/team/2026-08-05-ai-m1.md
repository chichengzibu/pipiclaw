## 关键设计决定

1. **接口对齐 ClaudeCode** — 5 工具 metadata (name/description/parametersJson/requiresPermission) 1:1 对齐, ChatManager 改 registerAgent(LlmAgentBrain) 即可无缝替换
2. **路径安全强制 sandbox/workspace** — 5 工具 + BashTool 都强制 cwd 在 userData/{sandbox,workspace} 内, 拒绝 `~/.ssh` / `C:\Windows\System32\` 等敏感路径 (单测覆盖)
3. **白名单 + execFile 数组传参** — BashTool 走 OpenClawGateway 的 60+ baseCmd 白名单 + `child_process.execFile` 数组传参 (不走 shell, 防注入), cwd 强制 sandbox
4. **多轮 LLM context** — assistant message 回写 tool_calls, tool message 回写 toolCallId+result, LLM 看到 tool 结果再继续 (OpenAI 格式)
5. **事件订阅 (非 IPC 直调)** — LlmAgentBrainEventBus 单例 + Set<handler>, UI 订阅, ChatManager 订阅, IPC 后续可通过 bus 推
6. **abort 支持** — AbortController 注入 LLM streamChat signal, 用户点"中止"立刻停 (避免长任务卡死)
