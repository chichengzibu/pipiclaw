# PipiClaw - 桌面 AI 自动化助手

基于 Electron + Vue 3 + OpenClaw 的国产桌面 AI 自动化助手，具有自我学习能力。

## ✨ 功能特性

### 🎯 核心功能
- **智能对话** - 自然语言交互，流式响应
- **任务执行** - 自动解析用户指令为可执行步骤
- **文件系统操作** - 读写、创建、删除文件，目录操作
- **Shell 命令执行** - 运行系统命令
- **剪贴板管理** - 读取和写入剪贴板
- **URL 打开** - 快速打开网站

### 🧠 Hermes 自我学习
- **行为观察** - 自动记录用户操作模式
- **模式识别** - 识别重复操作模式
- **技能生成** - 自动生成可重用技能
- **语义触发** - 自然语言匹配技能触发条件
- **热加载** - 新增技能无需重启

### 🛠️ 技能管理
- **技能导入** - 从文件或 URL 导入技能
- **技能市场** - 浏览和使用社区技能
- **技能卡片** - 查看技能详情、启用/禁用
- **自动提案** - 发现新操作模式时自动显示提案

### ⚙️ 系统配置
- **模型管理** - 支持 OpenAI、Anthropic、Azure、Ollama、自定义
- **权限管理** - 安全模式/标准模式/开放模式/自定义
- **MCP 配置** - 管理 Model Context Protocol 服务器
- **记忆管理** - Hermes 记忆系统
- **快捷键** - 全局快捷键配置
- **执行模式** - 安全/计划/全量模式

### 📊 任务管理
- **任务历史** - 完整的执行记录
- **任务重试** - 失败任务一键重试
- **任务导出** - 导出对话和任务记录
- **定时任务** - Cron 调度自动化任务
- **实时监控** - 任务执行过程可视化

## 📖 使用教程

### 1. 首次启动
1. 启动应用后，进入「设置」页面
2. 配置你的 AI 模型（支持 OpenAI、Ollama 等）
3. 根据需要配置权限（首次建议使用「标准模式」）
4. 返回「对话」页面开始使用

### 2. 对话与任务执行
#### 简单对话
```
用户：你好！
助手：你好！我是 PipiClaw，你的 AI 自动化助手。有什么我可以帮你的？
```

#### 执行文件操作
```
用户：在桌面上创建一个名为 test.txt 的文件，内容是 Hello World
```

系统会：
1. 解析用户指令
2. 生成任务步骤
3. 要求权限确认（如需要）
4. 执行并显示结果

#### Shell 命令
```
用户：列出当前目录的所有文件
用户：ping localhost
```

### 3. 技能使用与创建

#### 使用已导入的技能
1. 在「技能管理」页面查看可用技能
2. 确认技能已启用
3. 在对话中使用相关关键词触发

#### 自我学习流程（自动创建技能）
1. 重复执行 3 次类似的操作（如整理文件、重命名等）
2. 系统自动识别模式
3. 在技能管理页面显示提案横幅
4. 查看提案详情，确认无误后保存
5. 新技能自动生效

示例：
```
第1次：把桌面的 PDF 文件移动到 D:/Documents/PDF
第2次：把桌面的 Word 文件移动到 D:/Documents/Word
第3次：把桌面的图片移动到 D:/Pictures
→ 系统自动生成「自动文件分类整理」技能
```

### 4. 执行模式

#### 🔒 安全模式
- 所有操作需要手动确认
- 无自动执行
- 最安全选项

#### 📝 计划模式
- 显示执行计划预览
- 可编辑计划
- 确认后执行

#### 🚀 全量模式
- 自动执行所有操作
- 仅高危操作确认
- 最快速选项

### 5. 权限配置

#### 预设模板
- **安全模式** - 只读权限，禁止写入和执行
- **标准模式** - 常用功能开放，高危操作受限
- **开放模式** - 完全权限，无限制
- **自定义模式** - 精细控制每个权限类别

#### 自定义权限
可以单独控制：
- 文件系统（只读/写入/执行）
- 网络请求
- Shell 命令
- 剪贴板
- 系统操作
- 进程管理

### 6. 模型配置

#### 支持的供应商
- OpenAI (GPT-4, GPT-3.5)
- Anthropic (Claude 3)
- Azure OpenAI
- Ollama (本地模型)
- 自定义 OpenAI 兼容接口

#### 配置步骤
1. 在「设置 → 模型管理」页面
2. 点击「添加模型提供商」
3. 选择供应商类型
4. 填写 API Key 和其他配置
5. 测试连接成功后保存
6. 选择默认模型

### 7. MCP 服务器配置

1. 在「设置 → MCP 配置」页面
2. 点击「添加 MCP 服务器」
3. 填写服务器名称、命令、参数
4. 配置环境变量（可选）
5. 测试连接
6. 保存并启用

## 🔌 API 说明

### IPC 通信
前端通过 `window.electronAPI` 与主进程通信：

```typescript
// 发送消息
window.electronAPI.chat.sendMessage(conversationId, content, providerId, modelId)

// 加载技能
window.electronAPI.skills.list()

// 保存技能提案
window.electronAPI.learning.saveSkillProposal(proposal)

// 监听消息事件
const unsubscribe = window.electronAPI.chat.onMessage((data) => {
  console.log('收到新消息:', data)
})
```

### 技能定义
每个技能在 `skills/` 目录下有自己的文件夹，包含 `skill.md` 配置文件：

```markdown
# 技能名称

## 描述
技能描述文字

## 触发关键词
- 关键词1
- 关键词2

## 操作步骤
1. 步骤1
2. 步骤2
```

## 🛠️ 开发指南

### 代码规范
- 使用 TypeScript
- 遵循 Vue 3 Composition API 规范
- 使用 ESLint 检查代码

### 核心模块扩展

#### 添加新任务工具
在 `electron/task/TaskExecutor.ts` 中添加新的操作处理。

#### 扩展权限类别
修改 `electron/permissions/PermissionTypes.ts`。

#### 添加新的模型供应商
在 `electron/models/` 下添加新的供应商实现。

### 调试
- DevTools 可以通过顶部菜单打开
- 日志输出在 `console` 和日志文件中
- 日志文件位置：用户数据目录的 logs/ 文件夹
